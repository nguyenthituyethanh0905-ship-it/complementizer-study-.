# Anonymous review notice

This repository accompanies a manuscript currently under double-blind
review at the *International Journal of Corpus Linguistics*. To keep the
submission anonymous:

- No author names, affiliations, emails, or acknowledgements appear
  anywhere in this repository (code comments included).
- Commit history should not leak identity: either squash to a single
  commit under a generic name/email before publishing, or push through an
  anonymizing host (see below) instead of your personal GitHub account.
- Do not link this repository from a personal website, CV, or social
  media until after the review decision.

## Two ways to get a citable, anonymous URL now

**Option A — anonymous.4open.science (recommended for review).**
Push the repository to a normal (private or public) GitHub repo under any
account, then submit that repo's URL to https://anonymous.4open.science/ —
it generates a read-only, anonymized mirror URL with no GitHub username or
avatar visible. Put *that* URL in the paper's Data and Code Availability
section.

**Option B — a fresh, purpose-made GitHub account.**
Create a new account with a generic name (no personal identifiers), push
the repo there, and use its URL directly. Less convenient to migrate later
than Option A.

## After acceptance

Once the paper is accepted, deposit a snapshot of the final repository on
[Zenodo](https://zenodo.org) (GitHub → Zenodo integration gives it a
permanent DOI), restore author information, and update the manuscript's
Data and Code Availability section with the permanent DOI link in place of
the anonymized URL.
